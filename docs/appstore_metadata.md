**概要（Description）**
```
SounDrop（サウンドロップ）は、場所と時間に“声”を結びつける音声SNSです。

■ その場所にドロップ
お気に入りの場所で音声を録音して「ドロップ」。フォローしてくれた人の地図に表示されます。

■ 時間差公開（タイムロック）
ドロップは設定した時間が経ってから公開。待ち伏せなどを防ぎ、安心して使えます。

■ 現地で解禁（GPSアンロック）
ピンの半径50m以内に近づくと鍵が開いて再生できます。遠くても「ワープチケット」で解禁可能。

■ フォロー中心の安心設計
表示されるのはフォローしたアカウントの公開ドロップだけ。通報・ブロック・非公開アカウントなどの安全機能を用意。

さあ、街のあちこちに声を落としていこう。
```

## 3. 年齢レーティング（App Store Connect の質問）
本アプリは**ユーザー生成コンテンツ（音声）**を含むため：
- 「ユーザー生成コンテンツ／制限のないWebアクセス」→ **あり**
- モデレーション（通報・ブロック・非表示）を実装しているが、審査上は **17+（無制限のユーザー生成コンテンツ扱い）** になりやすい。
  → 規約・通報・ブロック・即時非表示を備えている旨を審査メモに記載。
- 暴力/性的/ギャンブル等：なし。

> 目安：**17+**。確実に通すなら 17+ で申請。

| データ種別 | 収集 | 用途 | 連携(identity) | トラッキング |

## 5. スクリーンショット
**必須サイズ：iPhone 6.7インチ = 1290×2796 px**（3〜10枚）。
- 6.5"(1242×2688)・5.5"(1242×2208) は任意。iPad対応するなら 12.9"(2048×2732) も。

**撮り方（Simulator が簡単）**
```
flutter run -d "iPhone 15 Pro Max" --dart-define=ENABLE_PURCHASES=false ...
# シミュレータで Cmd+S（または File > Save Screen）→ 1290×2796 で保存
```
**おすすめ構成（5枚）**
1. 地図＋ピン（ヒーロー）：「その場所に、音を落とす」
2. 解禁シート（再生＋波形）：「現地で“声”を解禁」
3. ドロップ画面（録音・タイムロック）：「時間差で公開」
4. プロフィール／フォロー：「フォローした人の声だけ届く」
5. 設定・安全機能：「通報・ブロックで安心」

> 文字入れ（キャプション）は任意。各言語ごとに用意。

## 7. ビルド〜提出手順
```bash
flutter create .
node tool/setup_native.js          # 権限・表示名・輸出コンプライアンス
flutter pub get
dart run flutter_launcher_icons    # 1024含む各サイズ
dart run flutter_native_splash:create
# β（課金OFF）でアーカイブ
flutter build ipa \
  --dart-define=USE_FIREBASE=true \
  --dart-define=MAPTILER_KEY=xxxxx \
  --dart-define=ENABLE_PURCHASES=false
```
1. `open build/ios/archive/Runner.xcarchive`（または Xcode で Product > Archive）。
2. Xcode Organizer or **Transporter** で App Store Connect へアップロード。
3. App Store Connect：アプリ作成（Bundle ID紐付け）→ §2 の情報・スクショ・§4 App Privacy・§3 年齢を入力。
4. ビルド選択 → **TestFlight** で内部テスト → 問題なければ **審査提出**。
