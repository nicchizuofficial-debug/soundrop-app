## 1. ストアの掲載情報（コピペ用）

**アプリ名（30字以内）**
```
SounDrop
```

**簡単な説明 / Short description（80字以内）**
```
その場所に音を落とす音声SNS。時間差で公開、現地50mで解禁。フォローした人の声だけが地図に届く。
```

**詳しい説明 / Full description（4000字以内）**
```
SounDrop（サウンドロップ）は、場所と時間に“声”を結びつける新しい音声SNSです。

■ その場所にドロップ
お気に入りの場所で音声を録音して「ドロップ」。フォローしてくれた人の地図にピンとして表示されます。

■ 時間差公開（タイムロック）
ドロップは設定した時間が経ってから公開されます。待ち伏せなどを防ぎ、安心して使えます。

■ 現地で解禁（GPSアンロック）
ピンの半径50m以内に近づくと鍵が開いて再生できます。その場所に行く体験そのものが楽しさになります。

■ フォロー中心の安心設計
地図に表示されるのは、フォローしたアカウントの公開ドロップだけ。通報・ブロック・非公開アカウント・即時非表示などの安全機能を備えています。

街のあちこちに、声を落としていこう。
```

## 2. データ安全性フォーム（Data safety）

収集して当社で扱うデータ（第三者販売なし／広告トラッキングなし）。
全データは**転送時に暗号化**、ユーザーは**アカウント削除でデータ削除を要求可能**（アプリ内に退会機能あり）。

| データ種別 | 収集 | 目的 | 共有 |
|---|---|---|---|
| メールアドレス | する | アカウント管理・認証 | しない |
| 音声（ユーザー作成コンテンツ） | する | アプリ機能（投稿・再生） | しない |
| 位置情報（おおよそ＋正確） | する | アプリ機能（投稿位置・現地解禁） | しない |
| ユーザーID | する | アプリ機能（アカウント識別） | しない |
| 写真（任意・プロフィール画像） | する場合 | アプリ機能 | しない |

- アプリ内課金の履歴は β では未収集（課金オフ）。製品版で有効化時に「購入履歴」を追加申告。
- 位置情報は**利用中のみ**取得。
- 「データはすべて暗号化されて送信されます」=はい。
- 「ユーザーはデータ削除をリクエストできますか」=はい（アプリ内の退会機能）。

## 3. コンテンツのレーティング（IARC 質問票）
- アプリのカテゴリ: ソーシャルネットワーキング/コミュニケーション = **はい**
- ユーザー同士の交流・ユーザー生成コンテンツの共有 = **あり**（音声投稿・フォロー）
- ユーザーの**現在地を共有**する機能 = **あり**（ピン位置・現地解禁）
- 暴力・性的描写・ギャンブル・薬物・差別 = **なし**
- → 結果は概ね「**13歳以上（Teen）**」想定。UGC の安全策（通報/ブロック/非表示/規約）を備えている旨を記載。

## 4. スクリーンショット（Play 要件）
- **スマートフォン用: 最低2枚**（推奨 1080×1920 など、16:9 or 9:16、PNG/JPEG）
- アイコン: 512×512 PNG（`assets/icon/` から生成可）
- フィーチャーグラフィック: **1024×500 PNG**（必須）

**おすすめ構成**
1. 地図＋ピン: 「その場所に、音を落とす」
2. 解禁シート（再生＋波形）: 「現地で“声”を解禁」
3. ドロップ画面（録音・タイムロック）: 「時間差で公開」
4. プロフィール／フォロー: 「フォローした人の声だけ届く」

---
## 5. リリース手順（内部テスト）
1. Play Console → アプリを作成（名前 SounDrop / 言語 日本語 / 無料）
2. 左メニュー「テスト → 内部テスト」→ 新しいリリースを作成
3. `app-release.aab` をアップロード（初回は Play App Signing に同意）
4. リリースノート（例: 「β版。タイムロック音声ドロップを試せます」）
5. テスターのメールを登録 → 配信リンクを共有
6. 並行して「アプリのコンテンツ」（プライバシーURL・データ安全性・対象年齢・広告の有無=なし）を入力
