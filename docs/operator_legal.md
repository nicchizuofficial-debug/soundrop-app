# 運営者の手続きチェックリスト（お金の受け取り・還元）

> ⚠️ 本書は一般的な整理です。実行前に必ず **税理士・弁護士（必要に応じ行政書士）** に確認してください。
> 特に「資金決済法（資金移動業の要否）」は専門家確認が必須です。

## A. 換金しない（β／v1：応援＝見える化のみ）— 手続きは軽い
あなたに入る課金収益を受け取るだけ。
- [ ] **Apple/Google 販売者設定**：Paid Apps 契約、銀行口座・税情報の登録、IAP商品の登録
      （※ β で課金を外す場合は不要）
- [ ] **開業届（個人事業主）or 法人**：継続収益があるなら税務署へ。確定申告で所得申告
- [ ] **特定商取引法の表記**：運営者名・連絡先・価格・返金条件等（有料機能がある場合）
- [ ] **利用規約・プライバシーポリシー**を公開URL化（実装済み）

## B. クリエイターに換金（送金）する（v1.1）— 追加で必要・重い
- [ ] **Stripe アカウント＋Connect 有効化**（プラットフォームの本人確認。クリエイターはKYC＝Connect Expressが代行）
- [ ] **資金決済法／資金移動業の要否確認（最重要・弁護士）**
      - ユーザー間送金の媒介は資金移動業登録が必要になり得る。
      - IAP（ストアが決済代行）＋ Stripe Connect の適切設計で回避しやすいが要確認。
- [ ] **税務（税理士）**
      - クリエイターへの支払いが「報酬」に当たる場合の **源泉徴収・支払調書**
      - **消費税／インボイス制度**（課税事業者か、手数料の扱い）
      - 「応援＝寄付/ギフト」か「対価」かの区分（設計・規約で明確化）
- [ ] **未成年の課金上限・保護者同意**、返金・チャージバック時の残高巻き戻し運用
- [ ] 規約に **送金・手数料・最低出金額・出金スケジュール** を明記
- [ ] （規模により）反社チェック／AML

## C. 自社アイテム（ワープチケット）販売 — 応援より簡単
ワープチケットは**あなたが自社デジタルアイテムを販売**し、代金は**あなたの売上**になる。
お金が他ユーザーに渡らないため、**資金移動業（送金）の論点は基本なし**。応援より法務負担は軽い。

必要なこと：
- [ ] **Apple/Google の IAP（消費型）必須**。ストアが15〜30%徴収、残りが収益。
- [ ] **税務**：売上として所得税／消費税（課税事業者なら）。開業届・確定申告・インボイス（税理士）。
- [ ] **特定商取引法の表記**：販売者名・連絡先・価格・**返金/失効条件**。
- [ ] **未成年の課金保護**（ストア機能＋規約）。

注意：**前払式支払手段**（資金決済法）
- チケットを「**残高として長期保有**」させると自家型前払式に該当し得る。
  - 自家型（自社内のみ使用）＝登録不要だが、**未使用残高が基準日に1,000万円超で届出・供託**。
  - **発行から6か月以内に失効**するものは原則対象外。
- → **安全側：チケットに有効期限（本アプリは付与/購入から180日）を設定**（実装済み）。
  小規模では基本問題にならないが、残高が積み上がる前に期限運用にしておくと安心。

> ワープチケット単体は応援より早く収益化しても負担が軽い（資金移動業・送金KYC不要）。
> ただし IAP設定・税務・特商法表記は必要。

## 取り分（既定）
- ストア（Apple/Google）：15〜30%（不可避。Small Business Programで15%の場合あり）
- 運営（あなた）：ストア控除後の 10%（`gifts.js`/収益画面の定数）
- クリエイター：残り（例 ¥500 → クリエイター ¥315）

## 進め方（推奨）
1. **β／v1：換金OFF で公開**（A のみ／本リポジトリは `ENABLE_PURCHASES=false` で課金UIを全て非表示）。
2. その間に税理士・弁護士に相談し、B（特に資金決済法・源泉/インボイス）の体制を構築。
3. 体制が整い次第、`ENABLE_PURCHASES=true`（必要なら `ENABLE_TIPPING=true`）で課金・出金を解放（v1.1）。
   - サーバー：`functions/`（verifyAndCreditGift / Stripe Connect）をデプロイ＋Secrets設定。
   - アプリ：`createGiftBackend()/createPayoutService()` を Firebase 実装へ。

## 相談先の目安
- 税理士：開業/確定申告・消費税・源泉徴収・支払調書
- 弁護士：資金決済法（資金移動業の要否）・規約・特商法
- Apple/Google：販売者・税・IAP規約／Stripe：Connectの本人確認・送金
